# k22-day21-react-router-ecommerce

1. Hướng dẫn chạy trên máy (Local)

# Bước 1: Clone dự án về máy
Mở Terminal / Git Bash và gõ lệnh:
git clone https://github.com/NGuyenVIetHUng2k3/k22-day21-react-router-ecommerce.git

# Bước 2: Di chuyển vào thư mục dự án
cd k22-day21-react-router-ecommerce

# Bước 3: Cài đặt dependencies
npm install

# Bước 4: Khởi chạy dự án
npm run dev

Mở đường dẫn hiển thị trên Terminal (thường là http://localhost:5173/) để xem giao diện.
